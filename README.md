# yapay_zeka_soru_cevap

C++ ile Minecraft benzeri bir voxel sandbox oyunu (SDL2 + OpenGL 3.3 + GLM + CMake). Dokular Bedrock texture pack'inden gelir (`Assets/`).

**Durum:** Mil 0 (pencere, kamera) ve Mil 1 (chunk, doku atlası, prosedürel dünya) tamam. Sırada Mil 2: yerçekimi, çarpışma, blok kırma/koyma.
