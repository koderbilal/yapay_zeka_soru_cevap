# yapay_zeka_soru_cevap

C++ ile Minecraft benzeri bir voxel sandbox oyunu (SDL2 + OpenGL 3.3 + GLM + CMake). Blok dokuları `Assets/` ve `Extra/`, eşya dokuları `Items/` klasöründen gelir.

**Durum:** Mil 0–2 tamam. Envanter, hotbar, çalışma masası, kalpler ve düşen eşya (Mil 3'ün büyük kısmı) oyunda. Su, lav, kaktüs, meşe yaprağı ve çöl de dünya üretiminde.
